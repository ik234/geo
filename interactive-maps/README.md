# Интерактивные карты Европы

Две самодостаточные HTML-страницы: происхождение названий дней недели и всех 12 месяцев. Интерфейс карт переведён на те же шесть языков, что и игра: RU/EN/PT/ES/DE/PL. Каждая страница включает в себя d3, topojson, контуры Европы и данные — внешних запросов нет, открывать можно прямо из файла.

- `europe-weekdays-interactive.html` — дни недели. Отдельных файлов с данными нет, всё внутри страницы.
- `europe-months-interactive.html` — месяцы: карта по группам традиций плюс таблица всех 12 месяцев для выбранного языка.

Язык интерфейса определяется по `navigator.languages`, а ручной выбор сохраняется в `localStorage` под тем же ключом, что и в игре: `geoDetectiveLang`.

## Данные

- `months-data.json` — 42 строки карты месяцев: код страны, название, номер группы в легенде, пояснение.
- `months-full-data.json` — 43 языковых варианта × 12 месяцев с этимологией и источниками, плюс раскладка «страна → языки». Генерируется скриптом.
- `month-names.json` — исходные названия месяцев по языкам, вход для скрипта.
- `build-full-months.py` — собирает `months-full-data.json` из `month-names.json` и зашитых в скрипт пояснений и источников.
- `month-table-ui.js` — не самостоятельный файл, а фрагмент кода таблицы месяцев; опирается на переменные окружающей области.

## Сборки нет

Данные и `month-table-ui.js` вклеены в HTML вручную. `build-full-months.py` обновляет только `months-full-data.json`; после этого изменения надо перенести в страницу руками. Проверить синхронность:

```sh
python3 build-full-months.py
```

Иконка вкладки встроена в каждую страницу как `data:`-URI: политика безопасности в шапке (`img-src` без `'self'`) заблокировала бы ссылку на отдельный файл, да и страницы намеренно не делают внешних запросов.

Опубликованные копии страниц лежат в `../detective/dist/weekdays.html` и `../detective/dist/months.html` и должны совпадать с этими файлами побайтово.
