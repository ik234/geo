# Географический детектив

Статический сайт для ребёнка 9 лет: география, флаги, животные; русский, английский и немного португальского.

## Запуск

```sh
python3 -m http.server 8765 --directory dist
```

Затем открыть `http://localhost:8765`.

## Состояние

- 175 флагов в максимальном уровне.
- Базовый уровень сохраняет прежние 24 флага.
- 5 животных.
- Раунды по 5 загадок, без таймера и штрафов.
- UI, сообщения, подсказки и базовые факты вынесены в i18n-словарь RU/EN/PT.
- Названия стран локализуются через `Intl.DisplayNames`.
- Есть режим исследования карты.
- Сборка не требуется: точка входа `dist/index.html`.
